Data Visualization · Assignment 2

Penguins, Five Ways

The same 342 penguin observations, recreated with Altair, D3, p5.js, Excel, and R + ggplot2. The browser versions are interactive; the Excel workbook and R image are included for comparison.

  • 342 observations
  • x = flipper length
  • y = body mass
  • color = species
  • size = bill length
  • opacity = 0.8

Run it locally

Open the whole site from the repository root with Python's built-in server:

python3 -m http.server 8000
# then open http://localhost:8000/

The Java server, p5.js data builder, Altair script, Excel builder, and R script each work from the repository root. See the README for every command.
